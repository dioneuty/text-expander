# Project Brief

## 프로젝트 개요

특정 키 또는 짧은 문구(트리거)를 입력하면 미리 등록된 단어·문장으로 자동 치환되는 **파이썬 기반 단축어(텍스트 확장) 프로그램**입니다.

메모장, 브라우저, 채팅 앱 등 **Windows 어디서든** 동작하며, **tkinter GUI**로 단축어를 관리합니다.

## 목적

반복적으로 입력하는 문장, 이메일 서명, 주소, 코드 스니펫 등을 단축어 하나로 빠르게 입력하여 타이핑 시간을 줄입니다.

## 핵심 목표

1. **트리거 → 확장 텍스트 매핑** — 키/문구와 치환 결과를 등록·조회·수정·삭제
2. **영속 저장** — 매핑 목록을 JSON 파일에 저장하고 재시작 후에도 유지
3. **전역 텍스트 확장** — 활성 앱과 무관하게 키보드 입력을 감지하고 트리거를 확장 문장으로 치환
4. **tkinter GUI 관리** — 목록·추가·수정·삭제를 GUI로 수행하고, 백그라운드 확장 서비스 ON/OFF 제공
5. **자유 트리거 입력** — 접두사(`;`, `@@` 등) 강제 없이 사용자가 원하는 문자열을 트리거로 등록

## 범위

### 포함

- 단축어(트리거)와 확장 텍스트 CRUD (GUI 중심)
- 매핑 데이터 JSON 영속화
- 전역 키보드 후킹 + suffix 트리거 매칭 + 치환
- tkinter 메인 창 (목록, 편집, 실행/중지)
- 시스템 트레이 또는 최소화 시 백그라운드 유지 (구현 시 선택)

### 제외 (초기 단계)

- 클라우드 동기화
- 다중 사용자·권한 관리
- 상용 텍스트 확장기 수준의 고급 매크로(조건문, 변수, 다중 커서 등)
- macOS / Linux 지원 (Windows 우선)

## 비즈니스 가치

- 개인 생산성 향상 (반복 입력 감소)
- 포트폴리오용 Python 데스크톱/유틸리티 프로젝트
- 전역 입력 후킹·GUI·영속화 패턴 학습

## 성공 기준

- GUI에서 단축어를 등록·수정·삭제할 수 있다
- 메모장·브라우저 등 **다른 앱**에서 트리거 입력 시 의도한 문장으로 치환된다
- 프로그램을 종료했다가 다시 실행해도 등록한 단축어가 유지된다
- 트리거는 접두사 없이 **자유 입력**으로 등록 가능하다
