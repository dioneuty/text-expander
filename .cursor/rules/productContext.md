# Product Context

## 해결하는 문제

- 이메일, 주소, 인사말, 자주 쓰는 코드 조각 등 **같은 텍스트를 반복 입력**하는 불편함
- OS 기본 기능만으로는 **개인 맞춤 단축어**를 유연하게 관리하기 어려움
- 터미널·특정 앱에 한정된 도구로는 **일상 입력 환경(메모장, 웹, 메신저)** 에서 쓸 수 없음

## 대상 사용자

- 반복 문구를 자주 입력하는 개인 사용자
- Python으로 Windows 생산성 도구를 만들고 싶은 개발자(본인)

## 사용자 경험 목표

| 목표 | 설명 |
|------|------|
| 어디서든 동작 | 활성 창과 관계없이 트리거 입력 → 즉시 확장 |
| GUI로 관리 | CLI 없이 창에서 목록·추가·수정·삭제 |
| 자유 트리거 | `addr`, `서명`, `myemail` 등 원하는 문자열 등록 |
| 즉각 반응 | 트리거 입력 완료 시 곧바로 확장 텍스트로 치환 |
| 안전한 저장 | 종료·재시작 후에도 등록 내용 유지 |

## 주요 사용 시나리오

1. **앱 실행** — GUI 창이 열리고 백그라운드에서 전역 확장 서비스가 시작됨
2. **단축어 등록** — GUI에서 트리거 `addr` → 확장 `서울시 ...` 입력 후 저장
3. **전역 사용** — 카카오톡·메모장·Chrome 등에서 `addr` 입력 → 주소로 치환
4. **단축어 관리** — GUI 목록에서 선택 후 수정·삭제
5. **서비스 제어** — GUI에서 확장 기능 일시 중지/재개

## 핵심 기능 (우선순위)

1. **P0** — 전역 키보드 후킹, suffix 트리거 매칭, 확장 치환
2. **P0** — JSON 매핑 저장/로드
3. **P0** — tkinter GUI: 목록, 추가, 수정, 삭제
4. **P1** — GUI에서 확장 서비스 ON/OFF, 상태 표시
5. **P1** — 트레이 아이콘·최소화 시 백그라운드 유지
6. **P2** — 다중 줄·특수문자 expansion, PyInstaller exe 패키징

## UX 원칙

- **GUI가 주 인터페이스** — CLI는 개발·디버그용 보조 수단
- 트리거 접두사를 강제하지 않음 — 사용자가 충돌을 스스로 피하도록 안내
- 동일 트리거 등록 시 명확한 한국어 오류 메시지
- 첫 실행 시 빈 저장소 자동 생성
- 전역 후킹 실패 시 GUI에 원인·해결 방법 표시

## 자유 트리거 주의사항 (사용자 안내)

- 일반 단어(`the`, `은`)를 트리거로 쓰면 의도치 않은 치환이 발생할 수 있음
- **긴·고유한 트리거**(예: `myaddr`, `회사서명`) 사용 권장
- 여러 트리거가 동시에 매칭되면 **가장 긴 트리거** 우선
